## 简介

扬帆云（YangFan Cloud）是一家面向个人用户、远程办公用户以及跨境业务用户的网络加速服务平台。根据公开信息显示，扬帆云提供全球节点资源、多档流量套餐以及专线网络服务，适合不同规模和使用需求的用户。 ([扬帆云][1])

平台提供周期套餐、长期流量套餐以及定制独享节点服务，用户可根据流量需求、设备数量以及线路类型进行选择。部分高阶套餐提供 IEPL 专线资源，用于提升跨区域连接体验。 ([扬帆云(yangfanyun)][2])

在节点覆盖方面，扬帆云节点主要覆盖香港、日本、新加坡、台湾、美国等热门地区，同时支持主流客户端导入使用，兼容 Windows、macOS、Linux、Android 与 iOS 等平台。 ([扬帆云(yangfanyun)][2])

根据公开资料，扬帆云支持流媒体访问及 AI 工具使用场景，但实际可用情况仍会受到节点状态、地区策略以及平台规则影响。 ([扬帆云(yangfanyun)][2])

本仓库主要用于整理扬帆云官网入口、套餐说明、扬帆云订阅获取方式、扬帆云使用教程以及客户端配置指南，帮助新用户快速完成部署与使用。
